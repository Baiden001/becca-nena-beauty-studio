Pictures for the customer screen when no sale is going on.

Name them idle-1.jpg, idle-2.jpg ... up to idle-8.jpg. They fade from one to
the next every 8 seconds. Any missing number is skipped; with none at all the
screen shows the logo and the word Welcome.

Best size: the shape of the customer screen. If it stands upright (portrait),
use something like 1080 x 1920 px; if it is wide (landscape), 1920 x 1080 px.
JPG, under about 500 KB each. No text that needs to stay readable at the very
edges, because the picture is cropped to fill the screen.
